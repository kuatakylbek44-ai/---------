# 3D көрінісін тексеру

Нақты себеп: PerspectiveCamera position=[5.8,3.6,7.4] нүктесіне жылжытылған, бірақ көрініске бағытталмаған. Оның бағыты [0,0,-1] болған. Көріністің бас нүктесі экран координаттарында [-2.192,-1.497] болып, [-1,1] көріну аймағынан тыс қалған.

Өзгертілген бастапқы файл: src/components/HeroScene.tsx. Камера onUpdate ішінде lookAt(0.65,0.8,0) арқылы көрініске бағытталды. reducedMotion кезінде demand режимі қолданылады. Бастапқы low-power және DPR шектеуі сақталды. Character, CSS, үш тілдегі мәтіндер және байланыстар өзгертілмеді. dist build арқылы жаңартылды.

Chrome headless, жергілікті Vite сервері, 1440×1000 және 390×1000 viewport өлшемдері тексерілді:

- Бастапқы бос көрініс скриншотпен расталды (before-*).
- Консольде орындалуды тоқтататын қате, Network-та жүктелмеген сұрау болмады. HDR және 3D мәтіннің қаріп файлдары HTTP 200 арқылы жүктелді.
- Canvas нақты өлшемдері 625×568 және 360×338; контейнерлері 627×570 және 362×340.
- SceneContent құрамында 6 тікелей объект, Character құрамында 12 mesh бар. useFrame орындалды, WebGL контексті жоғалмаған.
- Бастапқы камерамен уақытша күлгін куб көрінбеді (cube-*); камераны бағыттағаннан кейін куб пен модельдер көрінді (cube-aimed-*).
- Куб пен диагностика коды соңғы нұсқадан алынды.
- Соңғы скриншоттарда қара киімді кейіпкер, сұр кресло, көк ноутбук, үстел және монитор көрінеді (after-*).
- reduced-motion режимінде алғашқы кадр мен модельдер екі өлшемде де көрінеді (reduced-motion-*).
- IntersectionObserver немесе көріністі тоқтататын арнайы логика табылмады. Жоқ GLB файлына сілтеме қосылған жоқ.
- npm.cmd run build және npm.cmd run lint өтті.

Қалған ескертулер: Three.js Clock ескіргені, PCFSoftShadowMap орнына PCFShadowMap қолданылатыны және build JS көлемі туралы ескертулер. Олар бастапқы бос көріністің себебі емес.

Шектеу: нақты телефонда және жарияланған сайтта тексерілген жоқ; мобильді тексеру Chrome viewport эмуляциясында жүргізілді. JSON файлдары консоль мен Network бақылауларын сақтайды.
