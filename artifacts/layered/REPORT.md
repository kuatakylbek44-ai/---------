# Hero және 3D — қабатталған композиция

Өзгерістер тек Hero/3D кодына енгізілді. Үш тілдің контенті, контакттар, social links, mobile menu және қалған бөлімдер сақталды.

## Файлдар

- `src/App.tsx`: Hero ішіндегі мәтін және 3D қабаттары бөлінді; мәтіннің атауы/сипаттамасы жеке `hero-text-layer` ішінде. Контент өзгерген жоқ.
- `src/App.css`: жеке 3D қорабы алынды; мәтін алдыңғы, 3D артқы қабатта. Desktop-та объектілер мәтінмен қабаттасады; mobile/tablet-та сахна төмен жылжып, бет оқылатын әрі көрінетін жерде қалды.
- `src/components/HeroScene.tsx`: мөлдір Canvas, экран пішініне сай камера, жұмсақ бейтарап жарық пен көк/күлгін акценттер, жұқа тұғыр, ноутбуктың экран бағыты және артқы қақпағы нақтыланды. Бұрынғы demand render, горизонталь айналу, reduced-motion және fallback сақталды.
- `src/components/Character.tsx`: табиғи бас/дене пропорциясы, анатомиялық контурлар, жинақы спорттық дене, күңгірт футболка/шалбар, қайырылған шаш, нәзік бет және саусақ детальдары. Геометрия ауысқанда GPU ресурстары босатылады.
- `dist/`: production build жаңартылды.

## Blur

Мәтіннің `::before` қабатында `backdrop-filter` қолданылады: desktop 3.5px, tablet 3px, mobile 2.5px. Градиент пен маска әсерді шеттерінде жұмсақ азайтады. Canvas-тың өзінде `filter: none`, фон alpha=0. Blur тек мәтін аймағындағы артқы көрініске әсер етеді.

Production CSS ықшамдалғанда тек `-webkit-backdrop-filter` қалатын мәселе анықталып, vendor қасиеті бірінші, стандартты қасиеті соңғы жазылатын болып түзетілді. Дайын build-та стандартты қасиеттің есептелген мәндері қайта тексерілді.

Production скриншотындағы blur-ды ғана уақытша өшірумен пиксельдік салыстыру:

- Қабаттасқан аймақта орташа RGB айырмасы: 2.27235.
- Ашық монитор/үстел аймағында айырма: 0.
- Диагностикалық blur өшіру тек тест браузерінде жасалды; соңғы кодта эффект қосулы.

## Орындалған тексерулер

- `npm.cmd run build`: TypeScript және Vite build өтті.
- `npm.cmd run lint`: өтті, lint ескертуі жоқ.
- Chrome: 390, 768, 1440px; әр өлшемде kk/ru/en ауыстырылды. Көлденең overflow, page/console error және failed request жоқ.
- Production: үш өлшемде нақты Canvas көрінісі, жергілікті blur және CTA арқылы contact бөліміне өту өтті.
- Desktop-та mouse drag және 360° keyboard айналуы өтті; тек Y өзгереді, camera/pan/zoom өзгермейді.
- Native mobile touch: көлденең gesture айналдырады, тік gesture бетті scroll жасайды.
- Мәзір ашылуы/Escape арқылы жабылуы, foreground CTA hit target тексерілді.
- `prefers-reduced-motion` және тыныш күйде кадрлардың тоқтауы тексерілді.
- WebGL бастапқыда жоқ болғанда және контекст жоғалғанда иллюстрация көрсетілді.
- 12 тіл ауысуынан кейін GPU ресурстары тұрақты: 129 geometry, 8 texture. Көрініс шамамен 78,712 triangle; үздіксіз idle render жоқ.
- Кейіпкердегі ашық тізе, шаштың баспен қиылысуы және беттегі жолақтар скриншотпен анықталып, түзетілді. Соңғы desktop/mobile суреттері визуалды қаралды.

Негізгі дәлелдер: `final.json`, `final-verification.json`, `interactions.json`, `blur-pixels.json`.

Соңғы скриншоттар: `production-390.png`, `production-768.png`, `production-1440.png`. `blur-enabled.png` / `blur-disabled-diagnostic.png` жұбы selective blur әсерін көрсетеді. `no-webgl.png` және `context-fallback.png` — fallback сынақтары.

## Шектеулер

Нақты телефон, Safari және жарияланған сайт тексерілген жоқ; мобильді тест Chrome эмуляциясында өтті. Кейіпкер — анатомиясы жетілдірілген процедуралық semi-realistic модель, фотоскан емес. Vite 934.19kB 3D chunk көлемі туралы ескерту береді; ол lazy жүктеледі (gzip 249.24kB). Бұл жұмыс барысында сыртқы GLB, HDR немесе 3D қаріп қосылған жоқ.
